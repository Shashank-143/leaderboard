# 🚀 LeetCode Leaderboard

A modern LeetCode leaderboard built with Next.js, TypeScript, and TailwindCSS.

## Features

- **Dark Theme**: Beautiful black interface
- **Real-time Stats**: Automatic LeetCode stats fetching
- **Auto-sync**: Updates every 5 minutes
- **Responsive Design**: Works on all devices

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
